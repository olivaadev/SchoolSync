# 🚀 Meu Projeto

Uma aplicação com foco em gestão para foco estudantil desenvolvida com Node.js e TypeScript.

## 📸 Preview

![Preview do projeto](./public/preview.png)

## 🛠️ Tecnologias

- Node.js
- React
- TypeScript
- Python
- Docker
- PostegreSQL

## ✨ Funcionalidades

- Interface responsiva e simples
- Gestoria de produtos
- Componentes reutilizáveis
- Envio de formulários
- Cadastro de produtos
- Movimentação de estoque

## 🚀 Como executar

```bash
git clone https://github.com/seu-usuario/seu-projeto.git
cd seu-projeto
npm install
npm run dev
```

Acesse http://localhost:3000
